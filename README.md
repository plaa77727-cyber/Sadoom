# Phone Finder

เว็บไซต์ช่วยเลือกสมาร์ตโฟนจาก **งบประมาณ + Lifestyle** — แนะนำ ~3 รุ่นที่มีจุดเด่นต่างกัน
พร้อมเหตุผล โดยไม่มีระบบคะแนนหรือการจัดอันดับ ผู้ใช้เป็นคนตัดสินใจเอง

## วิธีเปิดดู
ดับเบิลคลิก `index.html` (หรือใช้ส่วนขยาย Live Server ใน VS Code) — ไม่ต้องติดตั้งอะไร

## โครงสร้างไฟล์
```
index.html            โครงหน้าเว็บ + ลำดับการโหลดไฟล์ JS
css/styles.css        สี ฟอนต์ และหน้าตาทั้งหมด (สีหลักอยู่ใน :root ด้านบน)
js/
├── config.js         ช่วงงบ, เกณฑ์ (เช่น แบตกี่ mAh ถึงนับว่าอึด)
├── data/
│   ├── phones.js     ข้อมูลมือถือ ← เพิ่มรุ่นใหม่ที่นี่
│   └── picks.js      Phones of the Month ← เพิ่มเดือนใหม่ที่นี่
├── utils.js          ฟังก์ชันช่วย (จัดรูปแบบราคา วันที่ ฯลฯ)
├── engine.js         ระบบแนะนำ (Lifestyle profiles, การเลือก 3 รุ่น, ข้อความเหตุผล)
├── store.js          รายการ Compare (จำไว้ใน browser)
├── components.js     ชิ้นส่วน UI: การ์ด, รูปมือถือ, ปุ่ม Compare
├── pages.js          หน้าต่าง ๆ: Home, Finder, Results, Detail, Compare, Picks, Guides
└── app.js            Router และการจัดการคลิก
docs/ARCHITECTURE.md  เอกสารออกแบบ
```

> ลำดับ `<script>` ใน `index.html` สำคัญ — ไฟล์ที่ถูกเรียกใช้ต้องโหลดก่อน

## ข้อมูล
ข้อมูลมือถือเป็นข้อมูลตัวอย่าง ราคา/สเปกโดยประมาณ ต้องตรวจสอบกับแหล่งทางการก่อนเผยแพร่
